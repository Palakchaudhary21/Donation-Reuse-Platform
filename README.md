# ♻️ ReWear – Donation & Reuse Platform

ReWear is a responsive web-based donation and reuse platform that helps people donate unused items and connect them with individuals who may need them.

The platform provides a simple and user-friendly way to donate, browse, request, and manage reusable items while promoting the idea of reducing waste and helping the community.

---

## 📌 Project Overview

**ReWear – Donation & Reuse Platform** is a frontend web application developed using HTML, CSS, and JavaScript.

The main purpose of this project is to create a digital platform where users can:

- Donate unused items
- Browse available donated items
- Search and filter items
- View complete item details
- Request available items
- Manage their donations
- Track their requests
- Save favorite items
- Receive notifications
- Manage their profile

The project focuses on creating a clean, responsive, interactive, and user-friendly experience.

---

## 🎯 Objectives

The main objectives of ReWear are:

- Encourage people to reuse unused items.
- Connect donors with people who need useful items.
- Make the donation process simple and accessible.
- Provide organized item browsing using categories and locations.
- Allow users to manage their donations and requests.
- Build a responsive platform that works across different devices.
- Promote a culture of sharing and reducing unnecessary waste.
